# 🚗 Premium Car Rental — نظام تأجير السيارات

نظام متكامل لتأجير السيارات مبني بـ **PHP (بدون أطر عمل) + MySQL**، بواجهة عربية (RTL) فاخرة ولوحة إدارة كاملة.

---

## ✨ المميزات

### للزبائن
- تصفح السيارات مع فلترة متقدمة (الماركة، الوقود، ناقل الحركة، عدد المقاعد، السعر، التواريخ)
- صفحة تفاصيل لكل سيارة مع معرض صور ومواصفات كاملة
- حجز تفاعلي: اختيار التواريخ، الخدمات الإضافية (GPS، مقعد طفل، سائق إضافي…)، حساب فوري للسعر
- **كوبونات خصم** (جرّب: `WELCOME10` أو `SUMMER20`) + خصومات تلقائية للمدد الطويلة
- دفع (تحويل بنكي بجميع البنوك المغربية / نقداً) مع توليد **فواتير قابلة للطباعة**
- لوحة تحكم العميل: الحجوزات، الفواتير، **المفضلة**، الملف الشخصي مع رفع صورة وتغيير كلمة المرور
- تسجيل دخول مع "تذكرني"، تفعيل الحساب بالبريد، واستعادة كلمة المرور

### للإدارة (`admin/`)
- لوحة تحكم بإحصائيات فورية (الإيرادات، الحجوزات، السيارات…)
- إدارة السيارات (إضافة/تعديل/حذف مع صور متعددة)
- إدارة الحجوزات وتغيير حالاتها، إدارة العملاء مع **صفحة تفاصيل لكل عميل**، تقارير، إعدادات

### الأمان
- كلمات المرور بـ **bcrypt** (cost 12)
- حماية **CSRF** في جميع النماذج الحساسة
- قفل مؤقت بعد 5 محاولات دخول فاشلة (15 دقيقة) + سجل محاولات
- جلسات محمية (`httponly`, `samesite`) وتجديد معرف الجلسة عند الدخول
- رفع ملفات آمن: فحص MIME الحقيقي، امتدادات بيضاء، منع تنفيذ PHP في مجلد الرفع

## 📦 المتطلبات

| المكوّن | الإصدار الأدنى |
|---|---|
| PHP | 7.4+ (يُنصح بـ 8.1) مع امتدادات: `pdo_mysql`, `mbstring`, `fileinfo` |
| MySQL / MariaDB | 5.7+ / 10.3+ |
| خادم ويب | Apache (مع `mod_rewrite` و`mod_headers`) أو Nginx |

أسهل طريقة محلياً: **XAMPP** أو **WAMP** أو **Laragon**.

## 🚀 التثبيت (خطوة بخطوة)

### الطريقة الأسهل — معالج التثبيت
1. انسخ مجلد المشروع إلى `htdocs/` (XAMPP) فيصبح المسار: `htdocs/car-rental-system`
2. شغّل Apache و MySQL
3. افتح في المتصفح:
   ```
   http://localhost/car-rental-system/install.php
   ```
4. اتبع الخطوات حتى تظهر رسالة النجاح ✅
5. (اختياري) اضغط **"إضافة 15 سيارة تجريبية"**
6. **احذف** `install.php` و`create-tables.php` و`create-admin.php` بعد الانتهاء

### الطريقة اليدوية — استيراد SQL
```bash
mysql -u root -p < database.sql
```
ثم (اختيارياً) افتح `add-all-cars.php` لإدراج السيارات التجريبية.

### إعدادات قاعدة البيانات
إن كانت بياناتك مختلفة عن الافتراضي، عدّل أعلى `includes/config.php`:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'car_rental_db');
define('DB_USER', 'root');
define('DB_PASS', '');
```

## 🗂️ بنية المشروع

```
├── includes/           # الإعدادات والدوال الأساسية + المصادقة + الهيدر/الفوتر
├── api/                # واجهات JSON (توفر، بحث، دفع، مفضلة، كوبونات)
├── admin/              # لوحة الإدارة الكاملة
├── customer/           # منطقة العميل (لوحة تحكم، حجوزات، فواتير، مفضلة، ملف شخصي)
├── assets/             # CSS / JS / الصور المشتركة
├── uploads/            # ملفات المستخدمين (سيارات، صور شخصية…)
├── database.sql        # مخطط قاعدة البيانات الكامل + البيانات الأولية
├── install.php         # معالج التثبيت (احذفه بعد التركيب)
└── *.php               # صفحات الموقع (الرئيسية، السيارات، الحجز، الدفع…)
```

## ☁️ النشر على Vercel (loc-voi.vercel.app)

المشروع مهيأ للعمل على Vercel عبر ملف `vercel.json` (runtime: `vercel-php@0.9.0`)،
مع جلسات محفوظة في قاعدة البيانات تلقائياً عند العمل على Vercel.

### الخطوات
1. **أنشئ قاعدة بيانات MySQL خارجية** (مجاناً مثلاً عبر [TiDB Serverless](https://tidbcloud.com) — متوافق مع MySQL) وسجّل بيانات الاتصال.
2. من [vercel.com](https://vercel.com) → **Add New → Project** → استورد مستودع GitHub هذا.
3. في شاشة الإعدادات:
   - **Project Name**: `loc-voi` (سيكون جزءاً من النطاق `loc-voi.vercel.app`)
   - أضف **Environment Variables**:

   | المتغير | القيمة |
   |---|---|
   | `DB_HOST` | عنوان خادم قاعدة البيانات |
   | `DB_NAME` | اسم قاعدة البيانات |
   | `DB_USER` | اسم المستخدم |
   | `DB_PASS` | كلمة المرور |
   | `DB_SESSIONS` | `1` |

   *(أو متغير واحد `DATABASE_URL` بصيغة `mysql://user:pass@host:port/dbname`)*
4. اضغط **Deploy**.
5. بعد اكتمال النشر افتح `https://loc-voi.vercel.app/install.php` مرة واحدة لإنشاء الجداول وحساب المدير.
6. افتح `https://loc-voi.vercel.app/add-all-cars.php` لإضافة السيارات التجريبية.

### قيود يجب معرفتها على Vercel
- **الصور المرفوعة** من لوحة الإدارة تُمحى مع كل عملية نشر جديدة (نظام الملفات مؤقت) — للاستخدام الجاد استخدم تخزيناً خارجياً (S3 ونحوه) أو انشر على استضافة PHP+MySQL تقليدية.
- **إرسال البريد** عبر `mail()` لا يعمل على Vercel — روابط التفعيل تُسجل في سجلات الأخطاء؛ استخدم خدمة SMTP عند الحاجة.
- `.htaccess` لا يُطبق على Vercel (تُستخدم إعدادات `vercel.json` بدلاً منه).

## 🔒 ملاحظات النشر في الإنتاج

1. اجعل في `includes/config.php`: `define('DEBUG_MODE', false);`
2. احذف سكربتات التثبيت: `install.php`, `create-tables.php`, `create-admin.php`, `seed-cars.php`, `add-all-cars.php`, `download-images.php`, `create_structure.php`
3. فعّل HTTPS (الموقع يفعّل كوكيز آمنة تلقائياً معه)
4. اضبط `SITE_URL` يدوياً إن لم يُكتشف تلقائياً
5. اضبط إعدادات البريد الحقيقي (الدالة `send_email` في `config.php`) أو استبدلها بـ PHPMailer/SMTP
